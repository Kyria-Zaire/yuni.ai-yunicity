# Dossier Technique — Yuni AI

## Pour : PIIEC / Bpifrance / Region Grand Est

### 1. Resume executif

Yuni AI est le premier assistant IA territorial souverain francais.
Deploye sur 3+ villes, il sert les citoyens avec des recommandations
personnalisees, du chat IA, de la voix, de la gamification et un
protocole civique ouvert pour le partage de donnees entre villes.

### 2. Innovation technologique

- Architecture microservice decouplée (FastAPI + Python 3.12)
- Modele principal : Mistral Large 2 (souverainete francaise)
- Routing intelligent Large/Small (economie x4 sur les couts IA)
- Cache semantique par similarite cosine (Qdrant)
- Stack 100% open-source sauf Mistral (accord DPA FR)
- Protocole civique ODBL : premier standard ouvert EU donnees civiques
- Conformite EU AI Act (audit trail complet — Boite Noire Civile)
- Federation EU : partage de donnees agregees entre villes europeennes
